Step 1

创作设定 / Project Setup

先定义项目 ID、目标词和运行配置。建议先用测试模式验证故事与视觉方向。 / Set the project ID, target words, and run options first. Test mode is the safest way to validate story and visual direction.

输入与配置 / Setup
先检查词义方案 / Review Senses First

输入单词后先确认义项，后面的故事和画面才会更稳定。 / Confirm the sense before generating the story and visuals.

Step 2

义项确认 / Sense Check

系统会先给出推荐义项，你可以直接采用，也可以切换到更适合教学画面的候选。 / The system suggests a preferred sense first, and you can keep it or switch to a more teachable visual interpretation.

系统先猜 / System Suggests First
先输入词表并点击“分析词义”，这里会展示每个词更适合教学的义项候选。 / Analyze your words first to see learner-friendly sense suggestions.

扩展词预览 / Related Word Family

当模式会把单个种子词扩展成词汇家族时，这里会提前展示系统补出的相关词。 / When one seed word expands into a word family, the system will preview the added related words here.

如果当前模式会自动扩词，这里会显示原词和系统扩展词。 / If the current mode expands one seed word, the original word and system added words will appear here.
确认好义项后再生成视频 / Start Video Generation After Sense Check

这一键会正式进入故事、关键帧、全局一致性以及后续交付流程；如果开启绘本测试模式，则会在关键帧阶段收尾。 / This starts story drafting, keyframe review, global consistency, and delivery steps. In storyboard-only mode, the run stops after approved keyframes.
